# Digital Wallet & Payment Platform

A modern, fast, and fully responsive digital wallet landing page built with Next.js, Tailwind CSS, and Framer Motion.

---

## 🚀 Project Overview

This project showcases a next-generation payment gateway and wallet management interface. It features smooth UI animations, interactive feature steppers, responsive image carousels, and an accessible layout designed for high conversion and modern financial platforms.

---

## ✨ Key Features

* **Interactive Hero Banner:** Auto-sliding banner carousel with custom control buttons, indicators, and Framer Motion visual effects.
* **Dynamic Feature Stepper:** Interactive feature highlight panel with auto-rotating progress indicators and filmstrip visual updates.
* **Unified Design System:** Clean color palette, polished typography, and consistent spacing across all components.
* **Fully Responsive:** Seamless layout adaptation for mobile, tablet, and desktop screens.
* **Performance & Accessibility:** Support for reduced motion preferences and optimized image assets.

---

## 🛠️ Tech Stack

* **Framework:** Next.js (React)
* **Styling:** Tailwind CSS
* **Animations:** Framer Motion
* **Icons:** Lucide React
